### Why Build Another Game Engine?

Building an engine from scratch is rarely about competing with commercial giants like Unreal or Unity; it is an exploration of foundational computing principles. In **Talu Engine**, the core objective was creating a zero-cost abstraction runtime that pairs Rust's memory safety guarantees with a lightweight custom scripting language, **WolfLang**.

```rust
// Simplified engine core loop
pub struct Engine {
    world: World,
    physics: PhysicsSystem,
    renderer: Renderer,
}

impl Engine {
    pub fn step(&mut self, dt: f32) {
        self.physics.update(&mut self.world, dt);
        self.renderer.draw(&self.world);
    }
}
```

### Deterministic Physics & Memory Layout

By structuring entities in contiguous memory buffers rather than pointer-heavy object graphs, cache misses were reduced drastically. The custom collision engine provides deterministic step simulations, ideal for reproducible game states.
