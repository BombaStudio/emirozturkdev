### The Butterfly Effect in Code

In 1963, Edward Lorenz discovered chaotic behavior while modeling atmospheric convection using three simple non-linear coupled differential equations:

```math
\frac{dx}{dt} = \sigma (y - x)
\frac{dy}{dt} = x (\rho - z) - y
\frac{dz}{dt} = xy - \beta z
```

With standard parameters ($\sigma = 10$, $\rho = 28$, $\beta = 8/3$), trajectories never intersect and never repeat, tracing out the famous butterfly-shaped strange attractor.

### Numerical Integration

Using fourth-order Runge-Kutta (RK4) integration rather than naive Euler integration ensures stable and visually faithful particle orbits inside the real-time simulation canvas.
